# Sponsors

PBI Lineage Lenz is free, open source, and stays that way.

## What sponsorship does not buy

**Features.** There is no paid tier, no "pro" build, no feature behind a login. Every
lens, the handoff file, the CLI, and the CI gate are available to everyone, forever. If
you find a capability you cannot use without paying, that is a bug — please report it.

This is written down because it is easy to promise and easy to erode. A tool that helps a
data engineer and a Power BI developer understand each other is only useful if both of
them can open it, and the person who most needs a handoff file is often the one with no
budget, no license, and no install rights.

## What it does buy

- **Time.** Issues answered, bugs fixed, connectors added.
- **Recognition.** Sponsors are listed below, and organisations can have a logo in the
  web app footer.
- **Priority triage.** Your issues get looked at first. Not a guarantee of a fix — an
  honest one is worth more than a promise nobody can keep.
- **Roadmap input.** Sponsors are asked before large decisions about direction.
